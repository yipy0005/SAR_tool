How queries are read
  • Drawn atoms fix the element, not the number of hydrogens. Draw an H to require one.
  • A any heavy atom · Q any heteroatom · * any atom or attachment point.
  • A drawn Kekulé ring matches aromatic rings; the dashed any bond matches every bond order.
    • {% if ketcher.available %}
  • In Ketcher, an R-group label (R1, R2…) means any substituent, and atom lists such as [F,Cl] or query properties set on an atom are searched as drawn.
    • {% endif %}
  • Stereochemistry is not compared.
